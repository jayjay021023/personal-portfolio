#Alisher Portfolio

shaxsiy portfoli saytim. HTML CSS va JavaScript yordamida yaratilgan.

#Loyiha haqida

bu loyiha mening frontend dasturlash bo'yicha bilim va ko'nikmalarimni namoyish qilish uchun yaratilgan. sayt 3ta sahifadan iborat.

_bosh sahifa_- Hero section, skills, counter
_men haqimda_-Biografiya , qiziqishlar, texnik bilimlar
_kontakt_-aloqa formasi va ijtimoiy tarmoqlar linklarim

##texnologiyalar

_HTML_- sahifa tuzilishi
_CSS_- dizayn(flexbox.grid.media queries)
_JS_-interaktiv funksiyalar
_git & github_-versiya nazorati
_vite_-loyihani yigish

##asosiy funksiyalar
_counter app_-soni oshirish, kamaytirish va qaytarish
_character counter_-belgilar soniini hisoblash
_responsive dizayn_-telefon, planshet va kompyuter
